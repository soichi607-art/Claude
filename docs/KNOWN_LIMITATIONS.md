# 既知の制約・未確認事項（2026-09-09 時点）

## 未確認（本セッションからアクセスできなかったため、導入時に確認が必要）
- ACE-Step 1.5 **モデル重み** のライセンス（huggingface.co に到達不可）
- Wan2.1 モデル重みのライセンス表記、無料 GPU での I2V-14B 動作、`generate.py` の出力仕様
- Google Colab / Kaggle の無料 GPU 利用条件・禁止事項の最新版
- Web Share API（ファイル共有）の iOS Safari 対応バージョンと Secure Context 要件（MDN / caniuse に到達不可）。実装は実行時に `navigator.canShare({files})` で判定し、非対応時はフォールバック
- 実機（Core 5 120U）の GPU / XPU / Quick Sync の可否。診断は開発コンテナ上で実行されたため、実機で `python scripts/diagnose.py` を再実行すること
- ACE-Step の CPU / XPU での実処理時間（10秒・30秒テストの実測で判断）

## 実装していないこと（意図的）
- 完全自動投稿、非公式 API、Cookie 操作、ブラウザ自動化
- YouTube / TikTok 公式 API による成績の自動取得（無料枠・審査要件を未確認のため手動入力）
- 実機での画像生成モデル・動画生成モデルの常駐
- 声のクローン、顔の模倣、メロディー・歌詞の流用、「〇〇そっくり」生成
- HTMX 本体の同梱（外部 CDN に到達不可だったため、同等機能の最小 JS を自前実装。docs/ADR.md ADR-005）

## 品質上の制約
- 歌詞はフレーズバンクによるルールベース生成。文学的品質は限定的。編集可能。
- 歌詞テロップのタイミングはセクション均等割で、ボーカルに厳密同期していない。
- 構成（Intro/Build-up/Drop）の自動検出はエネルギーに基づく推定。誤検出時はショートの編集プランが理想と異なる場合がある。
- モーショングラフィックス版は抽象的表現。基準画像未確定時は「基準画像未確定」プレースホルダーが映像に入る。
- 参考音源からは BPM/キー/エネルギー/構成/音色傾向のみ抽出。メロディーは抽出・流用しない。
- 低解像度プレビュー（SOA_RENDER_SCALE<1）では細線の色がクロマサブサンプリングで濁って見える。
- 収益化は保証しない。各プラットフォームの規約・申告 UI は変更されるため投稿時に公式ヘルプを確認。
- 温度監視は psutil が取得できる環境のみ（Windows では取得不可のことが多い → 「取得不可」表示）。
