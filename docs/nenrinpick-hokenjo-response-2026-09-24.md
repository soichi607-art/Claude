## 2. 保健所の指摘の読み解き

確認事項3点はすべて「**提出書類の記載と設備の整合**」を問うもの。

1. 「炊飯・煮込み」と「火気なし」の整合 → 答えは「IHクッキングヒーターと電気炊飯器（いずれも100V電気）」。ただし提出書類2には機材名の記載がなく、申込書にしか書いていない。
2. 保温方法 → 電気式（炊飯器保温／IH弱火／電気保温ジャー等）と温度管理の具体策を書く必要がある。
3. 冷蔵設備 → 「冷蔵ボックス」だけでは判断できないとされている。何で・何℃で・どう確認するかを書く必要がある。

指摘事項「ご飯ものは推奨食品外」について、確認できた一次情報の範囲：

- さいたま市「食品の臨時出店をされる方へ」ページ（検索結果の要約）：臨時出店で調理できる食品は原則として要領の別表に掲げるもの、**提供直前に加熱調理をする食品**を取り扱い、生ものは避ける、会場で下処理・仕込みを行わない、とされている。
- 埼玉県「行事に伴う食品の臨時出店に係る取扱要領」（令和5年4月1日施行と検索結果に記載）：別表の焼き物類の例示に「肉類の焼き物、フランクフルト、焼きだんご、今川焼」等。**別表にご飯もの（カレーライス・丼）が含まれるかは、この環境から原文PDFを取得できず確認できませんでした。**
- 埼玉県東松山保健所「イベントでの食品事故防止の手引き」：検索結果の要約では「カレーライス・丼などのご飯ものはイベントでは避けるべき」とされているが、**原文は未確認**。

米飯が高リスクとされる理由（一般に示されている根拠）：セレウス菌は耐熱性芽胞を作り加熱で死なず、28〜35℃で増殖し、嘔吐毒は熱で失活しない。炊飯後の常温放置・低温での長時間保温が事故原因になる（日本食品衛生協会、東京都保健医療局の解説）。

## 4. ヒアリング（回答をいただきたい点と私の提案）

1. **方針**：A／B／C／D のどれで進めますか。私の提案は「まず保健所に電話（下記スクリプト）→回答次第でBを本命、Dを次点」です。
2. **営業許可の種類と施設住所**：SoA Kitchenの許可は「飲食店営業」ですか。許可証に記載の住所は「寺山645-1」と「寺山648」のどちらですか。Bの場合、許可の範囲に弁当・そうざいの製造販売が含まれるかを保健所に確認する必要があります。
3. **機材の定格消費電力**：炊飯器・IHコンロの型番または定格W数。合計が1,500Wを超える場合、9/25までにオプション電源を申し込むか、ポータブル電源を持ち込むか。
4. **冷蔵設備**：電気式ポータブル冷蔵庫はありますか。なければ「保冷剤入りクーラーボックス＋庫内温度計（10℃以下を1時間ごと記録）」で書きます。あわせて、特製タレを**提供直前にIHで加熱して熱いままかける**運用に変えれば、非加熱食品（第1グループ）自体をなくせます。この変更は可能ですか（味の設計上の可否）。
5. **会場調理の品目数**：様式には「その場での調理は1品目のみ」とあります。Aの場合、会場調理を1品（カレー）に絞れますか。
6. **9/25説明会**：会場かTeamsか、出席予定はありますか。食品衛生の説明枠で上記を質問できます。
7. **保健所への電話**：ご本人が架電される前提で、下記スクリプトを用意しました。日程（9/24午後または9/25午前）をご指定ください。

4. 冷蔵設備は「保冷剤入りクーラーボックス＋温度計」で足りるか、電気式が必要か。
