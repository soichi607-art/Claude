# SoA EDM Studio 操作マニュアル（日本語）

最終更新: 2026-09-10

このアプリは **あなたの PC 上で動くローカルアプリ** です。インターネット上のサービスではないため、URL を開く前に PC で起動が必要です。iPhone からは同じ Wi‑Fi 経由で操作します。

---

## 0. 起動と終了

| 操作 | Windows | macOS / Linux |
|---|---|---|
| 初回セットアップ＋起動 | `start_windows.bat` をダブルクリック | ターミナルで `./start.sh` |
| 2回目以降の起動 | 同じ | 同じ |
| 手動起動 | `.venv\Scripts\activate` → `python run.py --open` | `source .venv/bin/activate` → `python run.py --open` |
| 前提チェックだけ | `python run.py --check` | 同じ |
| 終了 | 起動した黒いウィンドウで `Ctrl+C` | ターミナルで `Ctrl+C` |

起動すると `http://127.0.0.1:8000` がブラウザで開きます。開かない場合は手でこの URL を入力してください。

初回に必要なもの:
- **Python 3.11〜3.14**（python.org の最新版で構いません）。ACE-Step を使う場合だけ、ACE-Step 側の環境に 3.11 または 3.12 が必要です（ACE-Step 公式要件）。
- **FFmpeg**（`ffmpeg` と `ffprobe`）。用意する方法は 3 つ。どれでも可。
  - **A. winget（Windows・いちばん簡単）**: コマンドプロンプトで `winget install -e --id Gyan.FFmpeg` を実行 → 新しいウィンドウで起動スクリプトを再実行。`start_windows.bat` が FFmpeg を見つけられないときは、この自動インストールを実行するか聞いてきます（Y で実行）。
  - **B. zip を tools フォルダに入れる**: https://ffmpeg.org/download.html → Windows のアイコン → 配布サイト（gyan.dev または BtbN）の zip をダウンロード → 解凍 → 解凍してできたフォルダを **まるごと** このアプリの `tools` フォルダに入れる。**bin フォルダを探す必要はありません**。アプリが中の `ffmpeg.exe` / `ffprobe.exe` を自動で見つけます。
  - **C. フルパス指定**: `.env` の `SOA_FFMPEG` と `SOA_FFPROBE` に `ffmpeg.exe` / `ffprobe.exe` の場所を書く。
  - ※ ffmpeg.org で「Download Source Code」を選ぶとソースコード（プログラムの元）だけで実行ファイルは入っていません。Windows は上の A か B を使ってください。

## 2. 最初の1曲を作る（最短ルート・ACE-Step なし）

ACE-Step（AI 作曲）が無くても、手元の自作音源があれば投稿パッケージまで作れます。

1. **＋新規** → タイトル・テーマ（例 `Neon Rain`）・現代ジャンル・2010年代要素・スライダー・ボーカルを選び **「作成して3案のプロンプトを生成」**
2. プロジェクト画面の「3案のプロンプト・歌詞」で **案 A** を開き、「手動アップロード」に音源ファイル（wav/mp3/flac/m4a/ogg）を選び、**「自作または権利確認済み」にチェック** → **「この案の音源として登録」**
3. **3案比較** 画面 → 案 A の **「この案を採用」**（ACE-Step が無い場合は「フル生成する」のチェックを外す）
4. **MV編集** → **「フルMVを描画」**（進捗タブで待つ）
5. **ショート編集** → **「25秒 / 65秒 / 90秒 ＋ フル版 を一括描画」**（PC によっては数十分。進捗タブで確認）
6. **投稿準備** → **「テキスト・カバー画像・post_package.zip を出力/更新」**
7. 同じ画面でプラットフォームと動画を選び、タイトル・投稿文を確認 → **公開前チェック 8 項目** にチェック → **「共有画面へ」**
8. 共有画面（iPhone 推奨）→ **「① 投稿文をコピーして共有シートへ」** → 共有シートで YouTube / TikTok を選択 → アプリで **AI 生成コンテンツの申告** を有効にして公開 → アプリに戻り **「投稿済みとして記録」**
9. **分析** タブで、翌日以降に再生数などを入力

## 3. ACE-Step で AI 作曲する場合

1. `docs/ACESTEP_SETUP.md` に従い ACE-Step 1.5 の API サーバーを起動（Windows + Intel 内蔵 GPU: `setup_xpu.bat` → `start_api_server_xpu.bat`）
2. **設定** → 「ACE-Step 1.5」欄が **接続OK** になっていることを確認
3. **「10秒テストを実行」** → 進捗タブで完了を待つ（実測時間が記録されます）
4. 成功したら **「30秒テストを実行」**
5. 両方成功すると、プロジェクト画面の **「3案（A/B/C）の生成を開始」** が押せるようになります
6. モード: **Eco**（30秒×3案 → 採用1案だけ 2〜3 分化。初期設定）/ **Standard**（60秒×3案）/ **Overnight**（2〜3分×3案を順に生成、案ごとに休止）
7. **3案比較** で採用 → 「フル生成する」にチェック → 秒数（120〜180）を指定
8. 完了予定時刻は **実測値の中央値** からのみ表示されます。未計測なら「未計測」と出ます

失敗したときは進捗タブの赤い枠に理由が出ます（安全停止: 空きメモリ・空き容量・バッテリー・温度）。

## 4. AI 動画（任意）

1. **AERA** タブで基準画像（正面など）を登録し、代表者名を入れて **「確定する」**
2. **MV編集** → **「video_generation_pack.zip を出力」** → ダウンロード
3. **「Notebook をダウンロード (.ipynb)」** → Google Colab または Kaggle に手動でアップロードして上から順に実行
   - GPU 割当が無ければ中止（無料提供は保証されません）
   - ライセンス確認セルで、使うモデル・サービスの公式ページを確認して記入（記入しないと先へ進めません）
   - 3〜5秒テスト → 6〜10 シーン生成 → `ai_clips.zip` をダウンロード
4. **MV編集** → **「AI動画ZIP取り込み」** → ライセンス確認にチェック → 取り込む
5. **「フルMVを描画」** と **ショート編集の一括描画** をやり直すと、該当シーンが AI 動画に差し替わります

## 5. iPhone から操作する

1. PC の `.env` を開き、次を設定して再起動
   ```
   SOA_HOST=0.0.0.0
   SOA_AUTH_USER=好きなユーザー名
   SOA_AUTH_PASSWORD=長いパスワード
   ```
2. PC の IP アドレスを確認（Windows: コマンドプロンプトで `ipconfig` → IPv4 アドレス / macOS: システム設定 → Wi‑Fi）
3. iPhone を同じ Wi‑Fi に接続し、Safari で `http://PCのIP:8000` を開き、ユーザー名とパスワードを入力
4. Safari の共有 → **「ホーム画面に追加」** でアプリのように起動できます
5. 共有画面で「Web Share 非対応」と出た場合（`http://` の LAN 接続では制限されることがあります・未確認）は、画面内の **フォールバック手順**（動画を保存 → 投稿文をコピー → YouTube / TikTok アプリで投稿）を使ってください

## 7. よくある質問

- **ACE-Step が「未接続」のまま** → ACE-Step 側のサーバーが起動していません。手動アップロードで全工程を進められます。
- **日本語のテロップが出ない** → 設定 → フォント欄が「未設定」なら `.env` の `SOA_FONT_PATH_JA` にフォントファイル（例 `C:\Windows\Fonts\meiryo.ttc`）を指定。
- **描画が遅い／確認だけしたい** → `.env` に `SOA_RENDER_SCALE=0.5` を入れると低解像度で試せます。本番は削除するか `1.0`。
- **ハードウェアエンコーダー（Intel Quick Sync / NVIDIA NVENC / AMD AMF）が使われているか** → 設定 → 「エンコーダー実測」の採用欄。1秒の実動作テストに合格したものだけを採用し、描画中に失敗した場合は自動で `libx264` に切り替わります。
- **削除したい** → プロジェクト画面の一番下「プロジェクトを削除」（確認ダイアログあり）。
- **収益化** → 保証されません。各プラットフォームの最新規約と申告 UI を投稿時に確認してください。
